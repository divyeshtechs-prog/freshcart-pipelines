# FreshCart Pipelines

An end-to-end Data Engineering assignment demonstrating
Git and CI/CD, ELT, machine learning orchestration,
and event-driven messaging.

## Project Structure

- `elt/` - FreshCart ELT pipeline
- `iris_project/` - Mage machine learning pipeline
- `stream/` - RabbitMQ event streaming
- `tests/` - Automated tests
- `.github/workflows/` - CI/CD configuration
- `report/` - Assignment report and evidence

## Technologies

- Python
- Git and GitHub Actions
- Snowflake SQL
- Mage
- RabbitMQ
- Pytest
